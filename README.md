# 📊 Sales Performance & Business Intelligence Dashboard

## 1. Project Overview
This project focuses on analyzing sales team performance using Microsoft Excel. An interactive Sales Performance Dashboard was developed to monitor key performance indicators (KPIs), evaluate individual sales performance, and analyze monthly sales trends. The dashboard provides a clear visual representation of sales activities and business performance to support data-driven decision-making.

## 3. Project Objectives
* Analyze individual sales team performance.
* Monitor total calls and people reached.
* Evaluate the number of deals closed.
* Analyze monthly deal value.
* Visualize service performance across different divisions.
* Present business insights through an interactive dashboard.

## 4. Key Performance Indicators (KPIs)
| KPI | Result |
| :--- | :--- |
| **Total Calls** | 18,300 |
| **People Reached** | 3,619 |
| **Deals Closed** | 1,309 |
| **Total Deal Value** | $706,194.9 |

## 5. Tools & Technologies Used
* Microsoft Excel
* Pivot Tables & Pivot Charts
* Interactive Slicers
* Conditional Formatting
* Data Visualization & KPI Cards

## 6. Key Insights
* **Peak Month:** March recorded the highest monthly deal value of **$60,127.0**.
* **Lowest Month:** January recorded the lowest monthly deal value of **$57,863.2**.
* **Overall Volume:** The dashboard tracks **18,300** total calls and **1,309** closed deals.
* **Team Comparison:** Individual sales performance can be compared dynamically using the interactive dashboard.
